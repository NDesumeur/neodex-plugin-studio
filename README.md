# Studio de plugins

Crée un petit plugin NeoDex sans écrire de code, à partir d'un modèle : jeu de quiz, compteur ou page de liens. Aperçu en direct, et export du plugin complet.

+ NOUVEAU, choisis un modèle, remplis le formulaire : l'aperçu se met à jour à chaque lettre. Tes créations restent dans le studio (▶ UTILISER) avec leurs scores et leurs compteurs. ⇪ EXPORTER donne le plugin.json et l'index.js d'un vrai plugin NeoDex, à enregistrer dans un dossier.

Ses données (réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Studio de plugins → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
