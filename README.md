# Studio de plugins

Crée tes petites applis sans écrire de code, à partir d'un modèle :

- **Fiches de révision** : recto / verso, chaque fiche revient au bon moment (boîtes de Leitner).
- **Routine du jour** : une liste qui se remet à zéro chaque matin, avec ta série de jours complets.
- **Minuteur d'étapes** : des étapes chronométrées qui s'enchaînent avec un bip (sport, cuisine, pomodoro).
- **Suivi chiffré** : une valeur par jour, avec courbe, moyenne de la semaine et objectif.
- **Tirage au sort** : une roue qui choisit pour toi.
- **Comptes à rebours** : les jours avant tes dates, anniversaires chaque année compris.
- **Quiz**, **compteurs** et **page de liens**.

+ NOUVEAU, choisis un modèle, remplis le formulaire : l'aperçu se met à jour à chaque lettre. Ensuite, pour chaque création :

- 📌 **ÉPINGLER** : son résumé dans un widget de l'accueil de NeoDex.
- **Rappel chaque jour** à l'heure choisie : une notification de NeoDex.
- ⇪ **PARTAGER** : un code à envoyer ; un ami le colle dans son studio (+ NOUVEAU → Importer un partage) et reçoit la création, sans tes scores ni tes notes.

Ses données (réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Studio de plugins → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
